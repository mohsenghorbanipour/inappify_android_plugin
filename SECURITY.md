# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
[private vulnerability reporting form](https://github.com/mohsenghorbanipour/inappify_android_plugin/security/advisories/new)
and include:

- the affected SDK version;
- the Android API level and device or emulator details;
- a minimal reproduction;
- the expected and observed behavior;
- any known impact or mitigation.

Do not include real API keys, customer identifiers, purchase tokens, receipts,
or signing material. Acknowledgement and remediation details will be
coordinated through the private advisory.
